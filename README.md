# Hospital Management System

A simple Hospital Management System developed using **Java and SQL** to manage basic hospital information.

## Features

* Add patient details
* Update patient details
* Delete patient details
* View patient information
* Manage doctor information
* Manage appointment details
* Perform CRUD operations using SQL

## Technologies Used

* Java
* SQL
* JDBC

## Project Purpose

The main purpose of this project is to make hospital data management more organized and reduce manual record management.

## My Role

I worked mainly on the backend part of the project. I implemented CRUD operations and used SQL queries to store, update, delete, and retrieve hospital data.

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA or any Java IDE.
3. Configure the database connection in the JDBC configuration.
4. Create the required database and tables using the provided SQL queries.
5. Run the Java application.

## Learning

Through this project, I gained practical experience in **Java, JDBC, SQL, database operations, and backend development**.
